# Engineering Leadership Playbook

This repository contains reusable engineering leadership standards for communication, technical reviews, operational decisions, and leadership practices.

The playbook is intended for both human readers and AI assistants. Each standard is maintained as a focused Markdown document so it can be reviewed, versioned, and reused independently.

## Structure

- `communication/` — executive, email, Slack, and board communication standards
- `engineering/` — proposal, architecture, incident, RCA, and operational readiness reviews
- `leadership/` — hiring, feedback, decision-making, and operating principles
- `prompts/` — reusable prompts that invoke the standards
- `AGENTS.md` — primary instructions for AI agents
- `CLAUDE.md` — compatibility entry point for Claude-based tools

## Priority order

When standards conflict, apply this order:

1. Factual accuracy
2. Technical correctness
3. Operational impact
4. Explicit ownership and action
5. Conciseness
6. Style

## Current status

The executive communication standard is fully defined. Other documents are scaffolded for incremental development.
